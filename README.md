# Predictive Maintenance Dashboard

High-fidelity predictive maintenance dashboard for manufacturing lines.

## Tech Stack
- React + Vite
- Tailwind CSS
- Lucide React (Icons)
- Recharts (Charts)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:5173 to view the dashboard.

## Features
- **Dark Mode**: Deep navy/slate theme.
- **Dynamic Dashboard**: Updates based on Line Code selection.
- **Real-time Status**: Live FA Status, Machine Health, Efficiency Gauge.
- **Operational Details**: MTBF/MTTR metrics for each operation.
